# Dashboard Override

Use the AssetOrbit master palette with these dashboard-specific rules:

- Use Inter or the system sans-serif stack for headings and body text. Operational labels must stay compact and easy to scan.
- Use a 252px grouped navigation rail on desktop and an accessible overlay drawer below 920px.
- Keep page headings below 1.6rem and metric cards compact; this is a repeated-use operations console, not a marketing page.
- Prefer borders and one-pixel shadows over elevated cards. Avoid gradients and layout-shifting hover effects.
- Use navy for structure, blue for actions and focus, and semantic green, amber, and red only for status.
- Preserve visible keyboard focus, a skip link, descriptive icon-button labels, and reduced-motion behavior.
